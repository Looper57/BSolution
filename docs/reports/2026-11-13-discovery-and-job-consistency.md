# Public discovery and job lifecycle consistency

A fresh crawl of the production HTML found a self-canonical, indexable advert with no incoming HTML navigation links. The source feed already marked it closed and excluded it from listings, while B Solution's separately cached detail response still rendered it as open. The current collection, country filters and detail lookup must share a single cached collection per locale. There is no longer an independently cached id response that can resurrect a removed item. Visible job content, application destination and external-advert disclaimer remain unchanged.

The SEO graph gate now also verifies homepage reachability: reciprocal links inside a disconnected group cannot make those pages discoverable. A self-canonical indexable page found in navigation but absent from the canonical sitemap is now a blocking finding instead of an informational omission. Existing gates remain. Tests exercise disconnected cycles, a valid intermediate navigation hub, self-links, missing-sitemap failures and independently stale detail responses.

Actual audit findings also identified overlong search metadata. Shorten the law-firm title, the existing executive-search metadata in all four languages, German/Polish available-lawyer descriptions and the two employer landing descriptions. UAE search metadata uses native short country names while visible headings retain the full location. Job search titles reserve space for the brand suffix and end at a word boundary where possible; the visible original title is preserved. Canonicals, hreflang, service terms, approved evidence, fees and publication gates remain unchanged.
