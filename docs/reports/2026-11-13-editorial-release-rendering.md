# Reviewed editorial text reaches the real website

The private content queue previously stopped at a summary. A staging command now converts an exact current reviewed task into a minimal public candidate manifest, without changing the queue or overwriting source. The generic authority renderer consumes a validated promoted manifest and the sitemap uses its actual content-review date. Unsupported renderers, separately owner-gated service pages and case studies stay excluded; existing route, language, evidence and deployment checks remain mandatory.

Migrate the six already owner-approved compliance paragraphs from the hand-written entity section into this manifest. Preserve their exact wording and English-only scope, with a single rendered section and the same modification date. No new editorial approval or professional review is invented; the staging run replays the existing published approved revision. Private queue/source/reviewer data are not committed.

This is an actual queue-to-rendering adapter and reviewed-source release, not an unattended scheduler, authentication signature, new route generator or waiver of source review. Staging cannot deploy. Public byte-integrity checks fail builds for invalid manifests; they do not prove the truth of editorial assertions. Native browser and actual production checks must confirm the intended section and all six approved paragraphs. See docs/editorial-workflow.md for the supported workflow and limits.

A read-only automatic postflight listens to actual successful Production deployment statuses, verifies the still-current exact source and compares the real public section and sitemap to that manifest. Preview/failed deployments do not run it; superseded source is explicitly skipped. It retains a public-only report and cannot publish, roll back or access private queues. No unattended content-generation scheduler is introduced. Trigger reference: [GitHub deployment_status](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#deployment_status).
